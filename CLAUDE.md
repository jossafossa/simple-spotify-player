# Simple Spotify Player

## Git

- All work is committed directly on `main`. Do not create feature branches or
  worktrees for changes in this repo.
- Before committing, run `pnpm typecheck`, `pnpm lint`, `pnpm test` and
  `pnpm build`.
- Commit messages follow the existing history: `type: subject` (`feat`,
  `fix`, `style`, …), with a body that explains why.
- Pushing `main` deploys the app, so only push when asked.
